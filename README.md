# Career Docs Generator

Career Docs Generator is a web application that helps people create polished, professional career documents with the help of AI. Users fill in guided forms, choose a design, let AI refine their wording, and download a ready-to-send CV or letter in minutes. Beyond writing documents, the app also helps users tailor them to specific jobs, send them by email, and keep track of every application in one place.

## Overview

Writing a strong CV or cover letter takes time, and formatting it well takes even longer. Career Docs Generator removes both problems. The user focuses on their information, and the app handles the structure, wording suggestions, layout, and export. Every document is saved to a personal dashboard, so it can be revisited, updated, duplicated, or reused for the next opportunity.

## Features

### CV Builder

- Guided forms for personal details, professional summary, work experience, education, skills, certifications, projects, languages, awards, and references.
- A gallery of 16 templates across several styles:
  - **ATS friendly:** Classic, Harvard, Clean ATS
  - **Simple:** Minimal, Elegant
  - **Professional:** Professional, Executive, Corporate, Timeline
  - **Modern:** Modern, Nova, Slate, Metro
  - **Creative:** Studio, Bold, Mono
- Design controls for accent color, font, spacing, section order, hidden sections, and an optional profile photo.
- Live preview that updates while editing.
- Import an existing CV from a Word or PDF file and have it organized into editable sections automatically.
- Version history, allowing users to restore an earlier version of a CV at any time.

### Letter Generator

- Templates for five letter types: cover letters, internship applications, job application letters, recommendation letters, and resignation letters.
- AI writes the body of the letter from a short description of the situation.
- The same design options as CVs, so letters and CVs can share a matching look.

### AI Writing Assistant

- **Enhance:** improves the wording of any section to sound clearer and more professional.
- **Suggest alternatives:** offers different ways to phrase a sentence until it feels right.
- **Tailor to a job:** adjusts a CV or letter to match a specific job description.
- **ATS check:** compares a CV against a job description and highlights how to improve its chances with applicant tracking systems.
- **Email writer:** drafts a professional email from a brief description of what the user needs to say.
- **Help chat:** an in-app assistant that answers questions about using the platform.

### Sharing and Sending

- Export any document as a PDF or Word file, ready to upload, attach, or print.
- Create a public link to a CV that can be shared with recruiters, and turn it off at any time.
- Connect a Gmail account and send CVs and letters directly from the app as attachments.

### Application Tracker

- Record each job application with the role, company, job link, deadline, and notes.
- Attach the CV and letter used for that application.
- Follow progress through clear stages: Draft, Applied, Interview, Offer, Rejected, or Withdrawn.

### Accounts and Dashboard

- Sign up with email and password, or sign in with Google.
- A personal dashboard showing all CVs, letters, and applications, with search across everything.
- Profile management and the option to delete an account along with all its data.
- Light and dark themes.

### Administration

- An admin area with an overview of platform activity, user management, and content moderation, including the ability to revoke public CV links.

## Who It Is For

Students, graduates, and professionals who want to present themselves well without spending hours on writing and formatting. Whether someone is applying for a first internship, moving to a new role, recommending a colleague, or leaving a job on good terms, the app gives them a professional document quickly.
